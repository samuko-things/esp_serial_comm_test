# esp_serial_comm_test

it uses lidserial cpp library for linux

- make, build and run the test_cpp example code.
  > cd into the cpp folder
    ````
    cd cpp-serial-client
    ````
  >
  > mkdir build (i.e create a folder named build)
  >
  > enter the following command in the terminal in the root folder:
    ````
    cmake -B ./build/
    ````
    ````
    cmake --build ./build/
    ````
    ````
    ./build/test_cpp
    ````
